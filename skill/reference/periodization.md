# Periodization & Progressive Overload

## Macrocycle Structure

Divide the training period into phases:

### 1. Base Phase (40-50% of available time)

- Build aerobic capacity
- Increase volume gradually (max 10% per week)
- Mostly Zone 2 (conversational pace)
- Strength training: Foundation intensity (see `zones.md`) — build movement patterns before adding load
- Focus on running form and consistency

### 2. Build Phase (30-40% of available time)

- Introduce intensity (tempo, threshold work)
- Peak volume weeks occur here
- Strength training: progress to Strength intensity (70-85% 1RM or RPE 7-8), 1-2x/week
- Race-simulation long runs at goal pace segments

### 3. Peak/Race-Specific Phase (10-15% of available time)

- Reduce volume, maintain intensity
- Race-pace work
- Course-specific preparation (hills, terrain matching race course)
- Strength training: shift to Power intensity or hold Strength intensity, 1x/week — don't introduce new heavy loads this close to race day

### 4. Taper (1-3 weeks depending on event)

- Significant volume reduction (40-60%)
- Maintain some intensity
- Strength training: drop to Maintenance intensity (light, 2 sets)
- Focus on rest, nutrition, mental prep

## Microcycle Structure (Weekly)

### Principles (more important than specific days)

1. **Separate hard running days** - 48hr between quality running sessions (tempo, intervals, long run)
2. **Sequence strength deliberately** - pair lower-body strength with a hard run (same day, strength after running) rather than the day before a quality session; easy runs pair freely with any strength session
3. **Respect long run recovery** - Easy day (or full rest) after long runs
4. **Consistent weekly structure** - Same sessions on the same days each week helps athletes plan and builds a habit
5. **Strength stays every week** - Even in build/peak phases when running volume is high, keep at least 1 session/week rather than dropping it entirely

### Sample Week Templates

**Template A: Traditional 5-Day Runner**
| Day | Session 1 | Session 2 |
|-----|-----------|-----------|
| Mon | Rest | - |
| Tue | Run (quality: tempo/intervals) | Strength (lower body) |
| Wed | Run (easy) | - |
| Thu | Rest or cross-train | Strength (upper/core) |
| Fri | Run (easy) | - |
| Sat | Run (long) | - |
| Sun | Rest or very easy shakeout | - |

**Template B: Time-Crunched (4 running days)**
| Day | Session 1 | Session 2 |
|-----|-----------|-----------|
| Mon | Rest | - |
| Tue | Run (quality, 45-60min) | Strength (full body, 30min) |
| Wed | Rest | - |
| Thu | Run (easy, 40min) | - |
| Fri | Rest | Strength (full body, 30min) |
| Sat | Run (long) | - |
| Sun | Rest | - |

**Template C: High-Mileage Build (marathon/ultra)**
| Day | Session 1 | Session 2 |
|-----|-----------|-----------|
| Mon | Run (easy, recovery) | - |
| Tue | Run (quality: tempo/intervals) | Strength (lower body) |
| Wed | Run (easy) | - |
| Thu | Run (medium-long, moderate) | Strength (upper/core) |
| Fri | Rest or very easy shakeout | - |
| Sat | Run (long) | - |
| Sun | Run (easy, recovery) | - |

### Avoid These Patterns

- ❌ Two quality running sessions within 48 hours (tempo Tue + intervals Wed)
- ❌ Heavy lower-body strength the day before a quality run or long run
- ❌ Long run without an easy day (or rest) immediately after
- ❌ Dropping strength training entirely once running volume ramps up — reduce it, don't cut it

## Progressive Overload

**The 10% Rule**: Increase weekly running volume by no more than 10% per week—**for athletes building new fitness**.

### Adjust Progression Based on Athletic Foundation

| Foundation Level              | Progression Rate         | Rationale                              |
| ------------------------------ | --------------------------- | ------------------------------------------ |
| True beginner                 | 5-10% per week              | Everything is new; high injury risk        |
| Some experience (1-2 years)   | 10% per week                 | Standard progression                       |
| Strong foundation, returning  | 10-15% per week              | Body remembers; rebuilding is faster       |
| Recent high fitness           | Maintain or small build      | Already fit; focus on specificity          |

**Example**: A marathon finisher who took 3 months off can progress faster than a beginner. Their muscles, tendons, and cardiovascular system have adapted before. Where a beginner might take 20 weeks to reach 40km/week, someone rebuilding might get there in 10-12 weeks.

**However**: Always validate with the athlete. Time off due to injury requires more caution than time off due to life circumstances.

### Strength Training Progression

Strength progresses on a slower, more conservative timeline than running volume — tendons and connective tissue adapt more slowly than cardiovascular fitness:

- New to strength training: 4-6 weeks at Foundation intensity before adding meaningful load
- Some strength background: can move to Strength intensity within 2-3 weeks
- Increase load only when all prescribed reps are completed with good form at the target RPE
- Never progress running volume and strength load aggressively in the same week — pick one to push

### 3:1 or 4:1 Loading

- 3 weeks building load, 1 week recovery (reduce volume 30-40%)
- Or 2 weeks building, 1 week recovery for older/injury-prone athletes
- Athletes rebuilding can often handle 3:1; beginners may need 2:1
- Recovery weeks apply to both running volume and strength load — drop both together

### Long Run Progression

For a target marathon (42km), build the long run over 12-16 weeks:

```
Week 1:  16km
Week 2:  18km
Week 3:  20km
Week 4:  14km (recovery)
Week 5:  20km
Week 6:  22km
Week 7:  24km
Week 8:  16km (recovery)
...continue to 32-35km peak
```

Never increase the long run by more than 2-3km per week.

## Event-Specific Training Requirements

### 5K / 10K

**Minimum training time**: 3-5 hours/week at peak
**Minimum build time**: 8-12 weeks from solid base

**Weekly structure at peak**:

- 4-5 running days, 20-40km/week depending on experience
- One VO2max/interval session, one tempo session
- Strength: 2x/week year-round — speed work rewards power and stiffness that strength training builds

### Half Marathon

**Minimum training time**: 4-7 hours/week at peak
**Minimum build time**: 10-14 weeks

**Weekly structure at peak**:

- 4-5 running days, 35-55km/week
- One long run (16-19km), one tempo or threshold session
- Strength: 2x/week base and build, dropping to 1x/week in the final 2-3 weeks

### Marathon

**Minimum training time**: 5-9 hours/week at peak
**Minimum build time**: 16-20 weeks

**Weekly structure at peak**:

- 5-6 running days, 60-90km per week for experienced runners
- One long run (28-35km)
- One quality session (tempo or intervals)
- One medium-long run (18-22km)
- Remaining runs easy
- Strength: 2x/week base/build, 1x/week peak, maintenance-only in taper

### Ultra (50K+)

**Minimum training time**: 6-10 hours/week at peak
**Minimum build time**: 20-24 weeks

**Weekly structure at peak**:

- Long run or back-to-back long runs on weekends, time-based rather than distance-based (4-6hr)
- Time on feet matters more than pace — plenty of hiking-pace climbing if the race is trail/mountain
- Strength: 2x/week emphasizing durability (single-leg stability, eccentric strength for descents) rather than max power

## Physiological Adaptations: The "Why"

### Why Easy Training Works (Zone 2)

| Adaptation                      | Timeline    | Mechanism                                       |
| --------------------------------- | ------------- | ---------------------------------------------------- |
| Increased mitochondrial density  | 4-8 weeks    | More cellular powerhouses for aerobic energy         |
| Capillarization                  | 6-12 weeks   | More blood vessels deliver oxygen to muscles         |
| Improved fat oxidation           | 4-6 weeks    | Shifts fuel use from glycogen to fat                 |
| Increased stroke volume          | 8-12 weeks   | Heart pumps more blood per beat                      |
| Type I fiber development         | Ongoing      | Slow-twitch fibers become more efficient             |

Zone 2 is the foundation—never sacrifice it for more intensity.

### Why Threshold Training Works (Zone 4)

| Adaptation                 | Timeline   | Mechanism                                            |
| ---------------------------- | ------------ | -------------------------------------------------------- |
| Lactate clearance           | 2-4 weeks   | Muscles better at processing lactate                     |
| Raised lactate threshold    | 4-8 weeks   | Sustain higher intensity before lactate accumulates      |
| Improved muscle buffering   | 3-6 weeks   | Tolerate higher lactate levels                           |
| Mental toughness            | Immediate   | Learn to sustain "comfortably hard"                      |

### Why VO2max Intervals Work (Zone 5b)

| Adaptation                  | Timeline    | Mechanism                              |
| ----------------------------- | ------------- | ------------------------------------------- |
| Increased VO2max             | 4-8 weeks    | Maximum oxygen uptake improves             |
| Cardiac output               | 6-12 weeks   | Heart pumps more blood per minute          |
| Neuromuscular recruitment    | 2-4 weeks    | Better coordination at high speeds         |

Use sparingly—1x/week max, requires 48-72hr recovery.

### Why Strength Training Works for Runners

| Adaptation                        | Timeline     | Mechanism                                                          |
| ------------------------------------ | -------------- | ------------------------------------------------------------------------ |
| Improved running economy            | 6-10 weeks    | Less oxygen cost to hold the same pace, via stiffer tendons and better force transfer |
| Tendon/connective tissue stiffness  | 8-12 weeks    | Tendons store and return more elastic energy each stride                  |
| Neuromuscular power                 | 3-6 weeks     | Faster, more efficient motor unit recruitment for push-off               |
| Injury resilience                   | 12+ weeks     | Balanced strength around hips/knees/ankles reduces common overuse injuries |

Strength adaptations compound with running fitness rather than compete with it — this is why it belongs in every phase, not just as an off-season add-on.

### Adaptation Timelines Summary

| System                        | Time to See Changes | Time to Optimize |
| -------------------------------- | ---------------------- | ------------------- |
| Neuromuscular (coordination)     | 1-2 weeks              | 4-6 weeks           |
| Lactate clearance                | 2-4 weeks              | 6-8 weeks           |
| Aerobic enzymes                  | 3-4 weeks              | 8-12 weeks          |
| Mitochondrial density            | 4-6 weeks              | 12-16 weeks         |
| Capillarization                  | 6-8 weeks              | 16-24 weeks         |
| Cardiac adaptations              | 8-12 weeks             | 24+ weeks           |
| Tendon/bone strength             | 12-24 weeks            | 1-2 years           |

**Implication**: Base phases should be longer than athletes want. Intensity phases should be shorter. The deepest adaptations — including strength-training's tendon and connective-tissue work — take months. There are no shortcuts.
